Suivez votre compte Fortuneo à partir de vos exports

  1. Dans l'espace client Fortuneo, onglet Bourse, exportez l'historique des opérations (et si possible l'état du portefeuille) au format Excel ou CSV.
  2. Rangez tous vos exports dans un même dossier. Les doublons entre exports qui se chevauchent sont supprimés automatiquement.
  3. Choisissez ce dossier ici. Sur Chrome et Edge, il est mémorisé pour les prochaines visites.

Vos fichiers sont lus uniquement dans votre navigateur. Seuls les codes des titres sont envoyés à Yahoo Finance pour récupérer les cours.
